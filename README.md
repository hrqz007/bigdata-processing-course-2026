- `supplements/`：第一周、Linux和Maven补充教程。
- `course-control/`：课程规划及讨论材料。旧48次课教学方案和旧总控仅供理解设计演进，其编号、完成状态和学时安排不能替代当前课表。

## 使用与验证边界

材料面向Ubuntu 22.04、Hadoop 3.3.5等课程环境。新增软件的真实版本、Java更新号、Python版本与兼容性均需在教师母盘核验；本次归档的大小与SHA256核对不等同于Hadoop/Hive/Spark完整运行测试，也不等同于全部页面排版验收。

示例用户、商品和订单用于教学。旧包保留原有脚本，课堂应逐段阅读、解释和验证命令，不应直接一键执行未知脚本。修改配置前备份，限定操作目录；每次实验按需启动服务并检查健康状态，结束后正确停止。Spark local模式并不总需要HDFS/YARN。不要因普通连接或安全模式问题格式化NameNode。

参考教材仅作为引用背景，本仓库不提供出版社教材PDF。公开可浏览不自动授予第三方材料的再分发许可，本批未新增许可证。
